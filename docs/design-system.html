Sobre o Design System

Este design system foi desenvolvido especificamente para o Tesouro Estadual de Minas Gerais, em conformidade com as normas de acessibilidade WCAG 2.1 Level AA e o modelo eMAG 3.1 do Governo Federal Brasileiro.

Acessibilidade

Conformidade WCAG 2.1 AA

  • Contraste mínimo 4.5:1 para texto normal
  • Contraste mínimo 3:1 para texto grande (+18px)
  • Navegação completa por teclado (Tab, Enter, Esc)
  • Skip link "Ir para o conteúdo principal"
  • ARIA landmarks e roles em todos os componentes
  • Alt text em todas as imagens informativas
  • Labels associados a todos os campos de formulário
  • Mensagens de erro claras e associadas ao campo
  • Foco visível com outline de 2px mínimo
  • Suporte a zoom até 200% sem quebra de layout

Checklist eMAG 3.1

  • Identificação do idioma da página (lang="pt-BR")
  • Estrutura de headings hierárquica (H1→H6)
  • Formulários com label for/id associados
  • Tabelas com scope em th
  • Links com texto descritivo (sem "clique aqui")
  • Compatibilidade com NVDA, VoiceOver, JAWS
  • Aria-live regions para conteúdo dinâmico
  • Barra de acessibilidade com controle de fonte
  • LGPD: aviso de cookies e política de privacidade
